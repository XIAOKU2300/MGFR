# 地面放置与手柄操作合并版

候选程序：H:\MGFR\ControllerRoom-20261019\Project2\Build\Windows\MGFR.exe。

本版同时包含待确认的地面放置功能和新的手柄操作，基于现用完整 Unified 版本制作。唯一入口的候选仍先启动或复用原语音服务。旧入口备份在 LauncherBackup 中，尚未覆盖 H:\MGFR\启动MGFR.cmd。

## 常用操作

| 按键 | 功能 |
| --- | --- |
| 左手 Y | 打开或关闭快捷菜单 |
| 菜单里的右摇杆上/下 | 选择选项；每页最多显示五项，继续推会翻页 |
| 右手 A | 执行选项；摆放时保存 |
| 右手 B | 关闭菜单；摆放时取消并还原 |
| 长按左摇杆按键 0.8 秒 | 重新按地面放到玩家面前；菜单和摆放中不触发此快捷键 |
| 扳机或握键 | 在手柄交互模式中抓取，松开释放 |

快捷菜单包含：调整角色位置、重新放到面前、换肤、麦克风静音、字幕、自然/原待机、衣物穿脱开关、恢复全部衣物和鞋子、自动/手柄/裸手交互方式、找回小球、害羞表情。

## 摆放角色

先从 Y 菜单选择“调整角色位置”。让摇杆回中后，左摇杆相对于视线沿地面移动角色，速度上限 0.35 米/秒。右摇杆左右转向，上下缩放；按住 X 再上下推右摇杆，可以缓慢修正高度。A 保存当前会话的摆放位置；B 恢复进入摆放前的位置、转向、大小和高度。Home 键也能回到当前会话保存的位置。

日常互动时摇杆不会移动角色或给虚拟手叠加偏移。拿着衣物、鞋子或头发时，菜单会要求先松开再进入摆放、重新定位或换肤。手柄断线恢复后，需要摇杆回中才继续移动，按住按键重连不会误执行菜单动作。

## 手柄抓取

自动模式检测到有追踪的物理手柄时，使用手柄位置与扳机/握键生成抓取代理；没有物理手柄时保留原裸手追踪。也可以在菜单中固定为“手柄”或“裸手”。这种代理是抓取用的近似姿态，不会当成真实手指来遮挡画面。

抓取点约在手柄前方 7.5 厘米、下方 1.5 厘米。先松开扳机和握键，靠近布料、鞋面或鞋跟，再按下并移动手柄。衣物和鞋子共用原有归属与复穿规则；抓取键一直按着重连时，需要先松开重新按下。

## 验证范围

Unity 打包成功。实际打包程序的 49 项桌面检查通过，包括菜单按钮、死区、移动、转向、缩放、修正高度、保存/取消、断线后回中、皮肤切换，以及左右鞋和外层裙片的手柄代理抓取、拉脱、放下、拾取和复穿。原地面放置的 56 项桌面回归检查也通过。实际菜单截图见 Review2/controller-menu.png。

这些检查使用本机模拟手柄样本，没有读取或发送麦克风录音，也未做 PICO 实机验证。实体手柄按键映射、抓取点是否顺手以及真实贴地高度仍需戴头显确认。

按键读取采用 Unity XR 的通用输入功能：https://docs.unity.com/en-us/engine/6000.0/manual/input/xr_input 。PICO 串流时由当前 OpenXR 运行时提供具体映射。
