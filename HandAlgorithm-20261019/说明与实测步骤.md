# 手部算法自适应版（2026-10-19）

启动入口：[启动MGFR手部算法自适应版.cmd](../启动MGFR手部算法自适应版.cmd)。先退出旧播放器，再双击这个入口，沿用现有 SteamVR / ALVR 连接。旧入口仍指向各自旧版本。

## 已合入的算法

- **手型与深度：** 默认遮挡改为 19 段手指包络、鱼际连接和掌面构成的动态深度网格。长度由当前 SDK 关节点决定，粗细来自运行时关节半径；缺少半径时按掌宽估计。移除物理手固定 1.05 倍放大，避免视觉与交互使用两套尺寸。原 FBX 路径仅保留为兼容对照，默认关闭其渲染与逐骨更新。
- **轮廓与时序：** 使用 BeforeRender 的最新关节点驱动视觉，Dynamic 单独驱动物理滤波；不额外叠加运动外推。半径做时间滤波和异常跳变拒绝。shader 沿每眼观察方向后移 1 mm，替代沿法线收缩，保留轮廓。
- **捏合：** 指尖半径决定闭合距离，加入 22 ms 确认和松开滞回；缺指尖最多维持 60 ms，补出的点不能发起抓取。持续捏住后移到布面，每秒最多尝试 30 次获取目标，支持有距离上限的路径采样。
- **抓布：** 从当前骨骼变形后的真实渲染三角面拾取，以重心坐标和蒙皮权重选择可动 PMX 节点。固定拓扑 BVH 每次烘焙后更新包围盒，两只手共享同帧数据，替代对所有三角面的线性扫描。静态身体节点不可抓取。
- **牵引与接触：** 保留接触点偏移，避免抓上瞬间跳到指尖中心。牵引用隐式阻尼和包含转动惯量的有效质量，限制作用力并渐入；手部代理增加受限速度前馈。追踪中断、明显位置跳变或牵引过远会释放；丢追踪后需张手才能重新抓取。

## 头显实测

1. 放下手柄，把手完整伸入追踪视野，按 F8 显示算法包络。分别张手、并指、弯指和转掌，检查掌侧与指尖是否贴合。大手无需在本程序里统一放大。
2. 在角色前方和后方移动手，双眼分别观察遮挡；再快速横移，检查轮廓延迟。F8 关闭后恢复深度遮挡模式。
3. 先在布面前几厘米捏住，再保持捏合靠近裙摆/袖子/头发。进入可抓范围后缓慢拉动 3–5 cm，观察衣物是否跟随。距离和力均有限制，超过约束会自动松脱。
4. 松开拇指与食指。再把手移出追踪范围后闭手返回：应保持未抓取，张手后再捏才能抓上。

运行日志写入本目录的 `headset-*.log`。F8 为包络可视化，F9 为徒手/手柄切换。

## 能力边界

当前 PC OpenXR 链路按项目约束不提供头显透视相机或真实环境深度。这里估计的是 **SDK 手骨架的三维包络**，不是逐像素相机分割；没有重新训练 PICO 的识别模型。手套、手表、前臂以及硬件追踪彻底丢失不能靠这套骨架算法精确恢复。实际手型误差和串流时差需要用上述实测检查。

工程使用的 Unity API 依据：[Mesh.bindposes](https://docs.unity.cn/6000.2/Documentation/ScriptReference/Mesh-bindposes.html)、[XR 场景坐标设置](https://docs.unity3d.com/en/6000.0/Manual/xr-configure-projects.html)。

主项目仅按批准清单覆盖 6 个文件，新增 3 个算法文件及 Unity 元数据。原文件保存在 `Originals/`，附 SHA-256 清单；不自动回退，以免覆盖后续修改。
