# PICO 4 徒手测试

1. 启动 SteamVR 和 ALVR，确认 PICO 已连接。
2. 在头显系统设置中开启手部追踪，放下手柄，把双手举到头显摄像头能看见的位置。
3. 双击 `H:\MGFR\启动MGFR徒手测试版.cmd`。本轮使用这个新入口。
4. 查看电脑窗口右下角的“徒手交互”：左、右关节各应接近 26/26。分别张手和合拢拇指、食指，检查“捏合”是否对应改变。
5. 用食指轻推裙摆或后侧飘带；拇指和食指捏住衣料、缓慢拉动，张开后应松手。
6. 把手移出视野，抓取和遮挡应立即撤掉。F8 可显示手部拟合轮廓，便于检查位置；F9 可临时切回手柄。

当前采用关节拟合的手部几何遮挡，手掌/指节轮廓是近似。还未接入房间深度图。
回放检查已验证交互逻辑与左右眼的前后遮挡；这不代表头显关节传输已验证。需要真实张合手，不能仅凭 SteamVR 存在骨骼设备就认定成功。

运行日志自动保存在 `H:\MGFR\HandLab-20261018\headset-*.log`，每次生成新文件。

若关节为 0/26，保持本次播放器、SteamVR 与 ALVR 开着，让 Codex 读取日志确认扩展和子系统状态。
