# 稳手版 v8

入口：`H:\MGFR\启动MGFR稳手版.cmd`。退出旧播放器后启动，继续使用当前 SteamVR / ALVR 连接。无校准面板。

- 关节范围以手腕为中心放大 5%，手腕位置保持原输入路径；碰撞和捏合共同使用处理后的关节。
- 根据掌宽、掌长匹配手模型厚度，并略增加表面余量。网格骨骼中心仍与输出关节对应。
- 手腕与相对手腕的手指分别做随速度变化的低通处理；缓慢动作加强去抖，快速动作提高响应。
- 骨段长度约束减少追踪噪声引起的拉伸。
- 单个手指关节缺失时最多保持 60 毫秒，跟随仍有效的手腕；保持的数据不能开始新的捏合抓取。手腕丢失或 SDK 明确报告整手丢失立即撤掉交互。
- SDK 此次没有新数据时不清空手指，连续无数据超过 100 毫秒仍会失效。

算法参考：[1€ Filter 原作者说明](https://gery.casiez.net/1euro/)。没有增加模型依赖，没有更换 PICO 原始识别算法，也没有读取摄像头图像。

验证：Unity 编译成功，0 错误、1 个原有警告。`build-v8.log` 的模拟检查记录静止抖动 RMS 比例 0.269；以 1 米/秒移动的合成输入中，最大手腕位置滞后 0.0112 米；短缺点、保持过期、腕部丢失、骨长、弯指跟随与模型骨骼检查通过。这些是合成输入结果，不是头显实测精度。

原有抓布、释放、球抓取、双眼前后遮挡结果见 `Review-v8/hands-review.txt`。
运行日志新增到 `stable-headset-*.log`，包含实际观测关节数 observed，避免把短暂保持的关节当作当帧观测值。

独立工程：`Project-v8`。此前版本及主项目保留。本包未在真实头显上验收；长时间遮挡或上游错误手势仍需靠 PICO 追踪恢复。
