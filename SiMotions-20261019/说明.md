# 祀原版动作资源提取结果

已从本机终末地客户端提取 1041 个去重后的真实 AnimationClip，并保存完整字段和原始数据。

- 剧情与表情轨道：663 个。
- 祀专属身体动作：187 个。
- 祀控制器引用的共用动作：151 个。
- 祀敌人形态：40 个。

371 个片段的 ACL 压缩数据已解为 1113 组逐帧曲线，失败 0。角色控制器的 342 条引用（去重后 204 条）均已按 CAB + PathID 对应到真实片段。

## 查看入口

- `动作目录.csv`：按类别、动作名、时长检索；带原始数据与 JSON 的相对路径。
- `clips/`：祀专属片段、剧情表情、敌人形态的原始 AnimationClip 字节及完整字段 JSON。
- `controller-linked/clips/`：沿祀的实际角色控制器依赖补出的共用动作与额外专属动作。
- `sampled-curves/`、`controller-linked/sampled-curves/`：ACL 解压后的实际逐帧旋转、位移、缩放或浮点轨道。
- `acl/`、`controller-linked/acl/`：原始压缩数据，便于独立复核。
- `bundles/`、`controller-linked/bundles/`：对应的原始游戏 Bundle；均核对了解密后 MD5。
- `reports/final-summary.json`、`reports/controller-reference-validation.json`：最终数量与角色控制器引用核对结果。

## 已验证和仍需完成的部分

已验证：VFS 索引 CRC；抽取数据 MD5；所有 AnimationClip 对象按嵌入类型树完整读到结尾；1041 个源对象 SHA256；全部 ACL 采样值有限；采样文件长度符合轨道与帧数；全部控制器动画引用可解析。
尚未做：游戏原版与离线播放逐帧对照、骨架重定向、导出通用 FBX/VMD、接入 MGFR 的现有 PMX 模型。因此这里交付的是原版动作数据与解压曲线库，还不是可以直接双击播放的动作包。
范围是本机当前已安装资源。已包括角色控制器引用的共用动作；不宣称覆盖未安装版本、未来新增动作或未进入这些资源关系的动态剧情调用。部分 AnimationConfig MemoryPack 子结构仅解析到已确认的前缀，原始配置和状态均保留在 configs/，未把未解析的内容写成已验证。

## .samples 格式

全部小端。头 27 字节：ASCII `ACLBAKE1`；UInt8 trackType；UInt16 ACL version；UInt32 tracks；UInt32 frames；Float32 sampleRate；Float32 duration。之后按帧、按轨道排列。trackType=12 时每条轨道 10 个 Float32：qx,qy,qz,qw,tx,ty,tz,sx,sy,sz；trackType=0 时每条轨道一个 Float32。FloatBufferData 和 RootMotionBufferData 的序号需要结合原 JSON 的绑定和常量掩码解释，不能直接当成骨骼序号。
