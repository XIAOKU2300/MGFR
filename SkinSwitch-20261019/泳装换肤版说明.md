# 祀泳装渲染与运行时换肤

## 启动

- `H:\MGFR\启动MGFR泳装换肤版.cmd`：默认装载赤脚泳装 v4 与 ZMD 渲染，正常连接头显。
- `H:\MGFR\启动MGFR泳装换肤版（桌面）.cmd`：无需头显的桌面预览。
- **F5**：原服装 / 蓝白泳装切换。窗口左下也有两个皮肤按钮。
- **F11**：当前皮肤的 ZMD / 保留的旧渲染风格切换。
- 新入口使用独立构建 `Project8\Build9\Windows\MGFR.exe`；旧入口和原模型保留。

当前已完成独立程序。覆盖主项目五个现有脚本，需要按本会话 AGENTS.md 的覆盖协议取得明确同意；候选代码、备份和补丁均已准备。

## 模型与材质

输入：`H:\MGFR\converted\skins\si-swimsuit-barefoot-ankle-v4`，73,377 顶点、92,980 三角形、828 骨骼、40 个形变、14 材质槽。源目录保持不变，实际装载副本随包置于 StreamingAssets/skins 下。

脸、眼睛、头发沿用原角色的对应数据；身体和泳装使用本皮肤的 D/N 贴图。身体使用 ZMD 皮肤着色，泳装另建双面 Cloth Shader：反面法线正确翻转，移除不适合开口布片的倒壳描边，并保留透明衣料的混合与深度状态。不会把原服装 N/P/E 纹理套在泳装上。

`swimsuit_cloth_L.png` 的源通道含义尚未证实等同于原服装 P，所以使用明确的非金属粗糙度输入，并清除原衣服自发光。没有把未知通道假装成已经还原的金属度/AO。

## 切换行为

保持角色位置、朝向、缩放、同一组骨骼 Transform、表情索引、语音与注意力组件、同一 PhysX 世界。替换网格、材质和当前静止姿态；同步 idle 的骨架基准、物理目标和可抓表面的 BVH。顶点数量/布局变化时失效旧 GPU 蒙皮缓冲，避免切回原角色后消失。

切换前释放双手抓取，要求重新张手后抓取。按本皮肤的权重停用没有可见几何的旧衣物碰撞代理，避免手抓到不存在的原裙摆或袖子。

**物理范围：**这套已转换泳装的许多袖片/裙片仍属于基础蒙皮，没有原裙摆/袖子动态骨骼权重。本次验证了已有权重的飘带抓取，并没有为所有泳装布片新建完整布料模拟，不能据此宣称每片布都能独立捏拉。
