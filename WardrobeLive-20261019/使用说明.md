# 手部穿脱独立测试版

启动入口：`H:\MGFR\启动MGFR手部穿脱测试版.cmd`。在原绿边优化版基础上接入，默认祀赤脚泳装，保留原入口。

## 使用

1. 先张开手，再靠近衣物的扣点：罩裙腰缘、袖片上缘、腕饰、腿饰或墨镜边框。
2. 捏合后沿脱下方向拉开约 7～12 cm：罩裙/腿饰向下，左右袖片/腕饰向对应手臂外侧，荷叶边/墨镜向前。
3. 脱下后可手持移动与旋转。松手会放到角色身旁的置物位；在部件扣点附近重新捏合可以拿起。
4. 对准蓝色球提示的位置，把方向转回接近穿戴时方向，再张手穿回。穿回范围约 6 cm，角度约 35 度，随角色缩放。

F12：开关穿脱功能。关闭后原布料捏拉继续工作。

Shift+F12：全部衣物和饰件复原。

F5：换肤；F7：物理；F10：绿边优化；F11：渲染风格。换肤或切渲染风格时，穿脱状态会复原并重绑，避免残留旧网格与手持对象。

本版开放 8 个部件：罩裙、左右袖片、胸前荷叶边、左右腕饰、腿饰、墨镜。泳衣上装/下装保留。当前模型是赤脚版，没有独立丝袜；鞋子的脚姿态协调尚未实现，所以本版未开放鞋子穿脱。

## 接入内容

- 复用 `HandJointSource` 和 `HandPinchState`，使用真实有效指尖、捏合迟滞、先张手再获取的规则。
- 穿脱与旧抓取共享单手所有权。布料拉脱时交接 XPBD 当前顶点，释放该布片抓取，隐藏原布片并暂停对应组的模拟与碰撞；穿回时重置并恢复该组。
- 主角色与模拟布面分别更新可见三角形，保留其余衣物、骨架、表情和材质。
- 手追踪丢失、指尖数据缺失、手部跳变或关闭物理时取消待定拉脱。已手持部件放回置物位，恢复追踪后须重新张手。
- 手持部件当前采用拆下时的布面快照；未实现脱下后自由飘落的软布料模拟。

## 验证

Unity 6000.3.26f1 Windows Mono 构建成功，0 编译错误，1 条原有 XRSettings.enabled 弃用警告。

在真实打包程序中关闭 XR，使用合成关节帧跑一次短回放，`Check/replay.txt` 为 pass=True，退出码 0：

- 罩裙、左腕饰：捏合、定向拉脱、手持、放置、拾取及穿回全流程通过，覆盖模拟布片和普通蒙皮饰件两种路径。
- 袖片手持时追踪丢失：取消并放置，持续捏合恢复追踪不自动重新获取。
- 旧骨骼抓取与穿脱所有权互斥。
- 切换渲染风格、原服装和泳装往返后能重新绑定。

这次没有做头显实机手感、双手同时穿脱或长时间稳定性验收。默认抓取距离和拉脱参数是初始值。

程序：`Project/Build/Windows/MGFR.exe`。主要接入源码：`Project/Assets/MGFR/Wardrobe/`。构建日志：`build.log`；回放日志：`replay.log`。
