# ZMD 终末地渲染移植与验收

已为 MGFR 增加独立渲染风格。旧渲染源码、材质、模型、项目设置和旧启动入口保留；没有覆盖现有文件。

## 使用

- 双击 `H:\MGFR\启动MGFR终末地ZMD渲染版.cmd`：启动已打包版本，默认启用 ZMD。
- 按 **F11** 在 ZMD 与保留的当前风格之间切换。
- 原有启动入口继续使用原来的版本。
- 主项目模块目录：`H:\MGFR\unity-client\Assets\MGFR\RenderStyles\ZmdEndfield`。
- 从主项目重新打包时，启动参数加 `-mgfr-zmd` 即可启用；不加参数保留当前渲染。
- 本次独立包使用主项目当前的手部修复代码，未改变抓取或物理算法。

## 源模板分析和适配

模板是 Unity 2022.3.62f3 / URP 14.0.12 项目；MGFR 是 Unity 6000.3.26f1 / Built-in。直接搬入模板的 URP Renderer、后处理和材质会与当前管线冲突，所以独立移植四类角色着色方程，使用 Built-in 坐标、光照、阴影和深度接口。

| 源码 / 机制 | 在 MGFR 中的应用 |
| --- | --- |
| `S_Char_Face.shader` | 头部空间光向决定左右脸 SDF 通道，结合 CM 面罩、下颌过渡、柔光 Ramp 与唇部高光。每帧更新脸材质的头部向量，随头转动。 |
| `S_Char_Skin.shader` | 柔光 Ramp、Fresnel 第二色、AO 和受控高光；按祀的肤色、光照重新调参。 |
| `S_Char_Cloth.shader` | 金属度、AO、粗糙度分离控制，直接光高光、环境反射、衣料渐变和自发光。祀的 P 图 A 是光滑度，进入模板粗糙度公式前取反。 |
| `S_Char_Hair.shader` | RG/BA 双法线、切线各向异性高光带、顶部补光、环境反射、P 图分区与 AO。使用祀真正的 hair P；ST 只用于描边遮罩，不能当作 AO。 |
| `S_Char_Utils.hlsl`、`SmoothNormals.cs` | 运行时复制网格，按面积和法线夹角合并同位置顶点的平滑法线，再编码到 UV7；不写回 FBX 或原网格。保留柔光和描边数学。 |
| URP 阴影与深度边缘光 | 使用 Built-in 软阴影和相机深度重接；对角色材质单独做高光压缩，不改变 MR 纯绿背景和 UI。 |
| `FaceDirection.cs`、`GlobalRimLightController.cs` | 将头部坐标和轮廓光更新集中到独立运行时控制器。 |
| `S_Char_Eye.shader` | 阅读后保留当前眼球/睫毛/嘴部材质；模板眼球的 `ZTest Always` 与 MR 手部遮挡目标冲突，未原样移入。 |

没有安装模板附带的 URP、MagicaCloth 或 ASE，也没有变更 MGFR 原来的衣料物理。Per-object shadow 投影器、独立透明深度 Renderer Feature、Fur 并未完整复刻，不能把本移植等同于原模板全功能版本。

## 切换与资源管理

`ZmdRenderStyle` 等待原渲染初始化完成后，保存旧材质、网格、阴影和深度设置，为脸、身体、两组衣料、透明衣料、头发创建独立材质。F11 切回时恢复原引用和设置。ZMD 运行时数据集中在新目录下；共享角色贴图从既有 StreamingAssets 读取。

着色器添加了立体渲染宏和深度纹理接口，但桌面截图不能证明头显双眼正确性。材质内色调映射与较稳定的环境底光优先保证当前角色效果；该调参尚未覆盖多角色、多灯光或全部环境。

## 实际验收

- Unity Windows 构建成功，**0 errors / 3 warnings**。警告来自既有 XR API 的弃用提示。
- 编辑器和打包后的 Player 各生成五组同姿态、同相机对比图：全身、面部、侧脸、衣料、背面。
- 最终 Player 图片目录：`H:\MGFR\ZmdRender-20261019\ReviewPlayer1`，每张 `*-compare.png` **左侧是当前风格，右侧是 ZMD**。
- 检查了纯绿背景、透明衣料队列与深度写入设置、六次切换的材质引用恢复、错误品红像素；报告 `pass=True`。
- 对比截图在评测程序中固定角色姿态并暂停次级物理；截图用于比较渲染，不作为抓取或动画测试证据。
- 首次预热时有一次系统内存分配失败；使用同一最终项目、减少导入工作线程后完成渲染与构建。编辑器启动有既有 SearchDatabase 索引异常，最终 Player 正常退出。
- 原 ZMD 关键参考文件的 SHA-256 保持一致，来源记录在 `source-study-manifest.json`。移植记录与主项目保护文件校验保存在 `install-receipt.json`。
- 头显内双眼效果、手遮挡结合边缘光、动态头发稳定性、GPU 帧耗时仍需设备实测；本次没有宣称完成这些验收。
