## 仍存在的使用限制

完整客户端暂未整理为从干净克隆一键构建的工程。当前客户端组合了多个阶段的 Unity 源码与模块，根启动器还有原开发机路径；ZMD 参考目录排除了商业编辑器插件和角色资源。不能把本候选当作可安装成品，也不能将基础模拟服务测试视为头显、真实语音或完整 Unity 构建验证。

原私有仓库仍含 MC 的历史内容，因此应继续保留私有；本候选适合在维护者批准具体版本及目标仓库后，以独立源码快照建立新的公开仓库。不要直接改变原私有仓库可见性或强推重写其历史。
